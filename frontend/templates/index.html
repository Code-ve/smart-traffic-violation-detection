Core Capabilities

Object Detection

YOLO-powered real-time detection of vehicles, motorcycles, buses, trucks, and pedestrians with confidence scoring.

Vehicle Tracking

ByteTrack-based multi-object tracking assigns persistent IDs and records vehicle trajectories across frames.

Violation Detection

Rule-based engine detecting red-light violations, speed/zone violations, and configurable custom rules.

Evidence Capture

Automatic evidence image generation with bounding boxes, violation labels, track IDs, and timestamps.

Analytics Dashboard

Interactive charts and statistics powered by real processing data — vehicle counts, violation trends, and more.

Model Evaluation

Precision, recall, mAP metrics and inference benchmarking to assess detection model performance.
