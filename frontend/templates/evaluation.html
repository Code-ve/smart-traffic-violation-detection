📁 Dataset Information

Recommended Dataset

This system works with COCO-format object detection datasets. For traffic-specific evaluation, we recommend:

  • COCO 2017 — General object detection with vehicle classes (car, truck, bus, motorcycle, bicycle)
  • UA-DETRAC — Multi-object detection and tracking dataset for traffic scenarios
  • BDD100K — Berkeley DeepDrive dataset with diverse driving scenarios

Dataset Format

The evaluation script expects a YOLO-format dataset YAML file. Example structure:

path: /path/to/dataset
train: images/train
val: images/val
names:
  0: person
  1: bicycle
  2: car
  3: motorcycle
  5: bus
  7: truck

Running Evaluation

python scripts/evaluate_model.py --dataset path/to/data.yaml
